# XAUUSD Session Research Lab 🔬🪙

یک پلتفرم تحقیقاتی، آماری و ساختار بازار (Market Structure & Session Analytics) برای نماد طلا (XAUUSD).

> ⚠️ **سلب مسئولیت و مرزهای قطعی سیستم (Strict Operational Boundaries):**
> - این ابزار فقط **معاملات مجازی (Paper Trading)** دارد؛ هرگونه مسیر ارسال سفارش واقعی ممنوع است. سفارش‌های کاغذی تا دریافت فید معتبر و بازبودن بازار مسدود می‌شوند و معاملات خودکار تا تأیید موتور اجرای علّی غیرفعال‌اند.
> - برنامه API ارسال سفارش واقعی ندارد. از OANDA فقط برای **خواندن قیمت** استفاده می‌شود، آن هم در صورت تنظیم کلید دسترسی مجاز.
> - برنامه منحصراً روی شبکه محلی مک (`127.0.0.1`) در زمان روشن بودن سیستم اجرا می‌شود و از هیچ سرویس ابری، پس‌زمینه مداوم، daemon یا webhook خارجی استفاده نمی‌کند.
> - فایل‌های `demo_*` داده‌های مصنوعی و صرفاً برای تست نرم‌افزارند؛ هیچ‌گونه ادعای وین‌ریت، سوددهی یا برازش بر داده‌های ساختگی پذیرفته نیست.
> - حجم‌های نمایش‌داده‌شده صرفاً **Tick Volume** بروکری است و نباید با حجم‌های بازارهای آتی CME یا عمق بازار Bid/Ask واقعی اشتباه گرفته شود.

## 🏛 معماری سیستم

```
├── goldlab/
│   ├── types.py            # تعاریف داده‌ای Strongly-typed و مدل‌های Pydantic/Dataclass
│   ├── sessions.py         # سشن‌های سه‌گانه IANA (توکیو، لندن، نیویورک)، بازه مرجع آسیا و DST-Safe
│   ├── market_structure.py # سویینگ‌های تاییدشده، سطوح نقدینگی، FVG، بلاک‌های اوردر و شکست ساختار
│   ├── setups.py           # ۸ ستاپ ماژولار و مستقل با فرمول ریاضی شفاف و بدون نشت آینده
│   ├── data.py             # پایپ‌لاین ورودی چندگانه، بازنمونه‌گیری قطعی 1m به 5m/15m/1h و مانیتور سلامت
│   ├── simulator.py        # شبیه‌ساز ریسک: ورود اکیداً در Open کندل بعد، مدیریت بدترین حالت (Worst-case)
│   ├── calendar.py         # فیلتر خاموشی اخبار کلان (CPI, NFP, FOMC) با پشتیبانی از منطقه زمانی
│   ├── metrics.py          # محاسبات آماری Expectancy R, MAE/MFE, Profit Factor و بوت‌استرپ
│   ├── fixtures.py         # داده‌های ساختگی استاندارد برای آزمون‌های رگرسیون و تغییرات ساعت
│   └── engine.py           # موتور هماهنگ‌کننده مرکزی پژوهش
├── tests/                  # سوئیت آزمون جامع با پوشش بالا (Pytest)
├── app.py                  # سرور وب محلی FastAPI جهت رابط کاربری تعاملی (127.0.0.1)
├── static/ & templates/    # رابط کاربری سبک، سریع و کاملاً فارسی (RTL)
```

## 🚀 نحوه راه‌اندازی و اجرا روی مک

### ۱. فعال‌سازی محیط مجازی و نصب وابستگی‌ها:
```bash
python3.11 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### ۲. اجرای تست‌های اعتبارسنجی و رگرسیون:
```bash
pytest -q
```

### ۳. بررسی کیفیت کد و تایپ‌ها:
```bash
ruff check .
mypy goldlab
```

### ۴. راه‌اندازی داشبورد تحلیلی در محیط محلی (127.0.0.1):
```bash
python app.py
```
سپس مرورگر خود را در آدرس `http://127.0.0.1:8000` باز کنید.


## وضعیت اصلاحات بازار و Antigravity

- **TradingView Lightweight Charts** فقط کتابخانه نمایش کندل‌هاست؛ API زنده قیمت TradingView محسوب نمی‌شود.
- برای **قیمت زنده خواندنی**، تنها آداپتور فعلی OANDA v20 (XAU_USD) است. دسترسی به نماد به منطقه و نوع حساب بستگی دارد؛ بدون کلید معتبر قیمت زنده نداریم.
- برای فعال‌کردن فید، متغیرهای `OANDA_ACCOUNT_ID`، `OANDA_API_TOKEN` و `OANDA_ENV=practice` را فقط در محیط محلی تنظیم کنید. کلید را در Git ثبت نکنید.
- وقتی فید معتبر نیست، بازار بسته است یا Quote کهنه است، سفارش جدید رد می‌شود؛ قیمت‌های دمو یا تاریخی هیچ‌وقت جایگزین Tick اجرایی نمی‌شوند.
- **PAPER_AUTO فعلاً عمداً قفل است.** تشخیص سیگنال روی کندل تاریخی با مجازبودن اجرای سفارش لحظه‌ای یکی نیست.
- روی چارت محدوده سشن‌های آسیا، لندن، نیویورک و هم‌پوشانی روزهای اخیر دیده می‌شود؛ سطوح و علامت‌ها قابل خاموش‌کردن‌اند.
- بخش «مرکز یادگیری» فعالیت واقعاً ثبت‌شده Antigravity، خطاها و پیشنهادها را نشان می‌دهد. این بخش صرفاً ثبت‌کننده و رابط تحویل کار است، نه Agent زنده بدون اتصال واقعی.
- برای ثبت چرخه پایش در زمان روشن‌بودن مک، دستور `bash scripts/agent-observe-loop.sh` را اجرا کنید. این حلقه به‌صورت دوره‌ای شواهد را در `agent-work/REVIEW_TASK.md` می‌نویسد و به‌تنهایی مدل AI را اجرا نمی‌کند.
- پروژه را در Antigravity باز کنید و دستورهای `AGENTS.md` را به عامل معرفی کنید. اجرای زمان‌بندی‌شده AI فقط اگر در نسخه نصب‌شده پشتیبانی و از سوی کاربر فعال شود انجام می‌گیرد.

برای تست: `python -m pytest -q`؛ برای بررسی سازگاری JS: `node --check static/js/dashboard.js`.
